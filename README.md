Sum up 23 November's world news in one image: your program writes one image of the day's news, an AI judge compares the images two at a time, and the 50 best win rates share $100: $20 for 1st place, $12 for 2nd, $6 for 3rd, $2 each for 4th to 10th and $1.20 each for 11th to 50th.

This entry is a one-page newspaper front page for Monday 23 November 2026: COP31 collapses in Antalya, an AI-driven sell-off rattles world markets, a Russian strike kills 10 near Kyiv, a Russian frigate is sunk off Benghazi, Trump threatens to sink Iranian ships, Democrats take their biggest House majority since 1992, a Riemann Hypothesis proof is claimed, and South Korea's exports pass $1 trillion. The program copies the image in this repository to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
